# LAB 7 - GTICS 2026-2

Solución basada en las estructuras vistas en clase: Spring MVC, Thymeleaf, Spring Data JPA, Query Methods, relaciones JPA, fragmentos Thymeleaf, RedirectAttributes, @ModelAttribute, @Valid, BindingResult y messages.properties.

## 1. Base de datos
Ejecutar `lab6.sql` en MySQL.

## 2. Configuración
Revisar `src/main/resources/application.properties` y colocar usuario/contraseña de MySQL.

## 3. Ejecutar
Abrir como proyecto Maven en IntelliJ y ejecutar `Lab7Application`.

## 4. URL
`http://localhost:8080/`

## Ramas y commits incluidos
- `main`: commit inicial vacío.
- `develop`: resultado final luego del merge de `feature/product`.
- `feature/customer`: estructura/navegación + gestión de clientes.
- `feature/product`: catálogo de productos + pedidos.

## Importante para GitHub
El ZIP incluye el historial `.git`. Cree un repositorio VACÍO en GitHub (sin README ni .gitignore), configure el remote y haga push de las cuatro ramas. Ver `GIT_Ramas.txt`.
